## 📘 Assignment 1 – Working with NumPy

### Objective

Understand NumPy arrays, statistical calculations, array manipulation, and mathematical operations.

### Tasks Performed

**1. One-dimensional array**

* Create an array containing integers from 1 to 20.
* Calculate the sum, mean, median, and standard deviation.
* Find the indices of elements greater than 10.

**2. Two-dimensional array**

* Create a 4 × 4 array containing numbers from 1 to 16.
* Display the array and its transpose.
* Calculate row-wise and column-wise sums.

**3. Random arrays**

* Generate two 3 × 3 arrays with random integers between 1 and 20.
* Perform element-wise addition, subtraction, and multiplication.
* Calculate the dot product.

**4. Reshaping and slicing**

* Reshape a one-dimensional array of 12 elements into a 3 × 4 array.
* Extract the first two rows and last two columns.

### Key Concepts Learned

`np.array()`, `np.sum()`, `np.mean()`, `np.median()`, `np.std()`, `np.where()`, `np.transpose()`, `np.random.randint()`, `np.dot()`, `reshape()` and array slicing.

## 📗 Assignment 2 – Working with Pandas

### Objective

Learn how to create and manipulate DataFrames for basic data analysis.

### Tasks Performed

**1. DataFrame creation and exploration**

* Create an employee DataFrame containing names, ages, departments, and salaries.
* Display the first five rows.
* Generate summary statistics for age and salary.
* Calculate the average salary of employees in the HR department.

**2. Feature creation**

* Add a `Bonus` column calculated as 10% of each employee's salary.

**3. Filtering**

* Filter employees whose ages are between 25 and 30.

**4. Grouping and aggregation**

* Group employees by department.
* Calculate the average salary for each department.

**5. Sorting and exporting**

* Sort employees by salary in ascending order.
* Save the sorted DataFrame to a CSV file.

### Key Concepts Learned

`pd.DataFrame()`, `head()`, `describe()`, Boolean filtering, `groupby()`, `mean()`, `sort_values()` and `to_csv()`.

## 📊 Assignment 3 – Working with Matplotlib

### Objective

Practice data visualization techniques to present information clearly and effectively.

### Tasks Performed

**1. Line plot**

* Visualize the given X and Y values.
* Add a title, axis labels, and grid.

**2. Bar graph**

* Visualize marks scored by students.
* Customize bar colors and add a title.

**3. Pie chart**

* Represent revenue distribution across North America, Europe, Asia, and other regions.
* Label each region.
* Highlight the region with the highest revenue.

**4. Histogram**

* Generate 1,000 random integers between 1 and 100.
* Plot their frequency distribution using a histogram.

### Key Concepts Learned

`plt.plot()`, `plt.bar()`, `plt.pie()`, `plt.hist()`, `plt.title()`, `plt.xlabel()`, `plt.ylabel()`, `plt.grid()` and `plt.show()`.
